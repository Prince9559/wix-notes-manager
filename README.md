# Wix Notes Manager

A simple Wix-style self-hosted Notes Manager application built using React, Node.js, Express, and MongoDB.

## Features

- Add Note
- Edit Note
- Delete Note
- Fetch Notes

## Tech Stack

Frontend:
- React.js
- Axios

Backend:
- Node.js
- Express.js

Database:
- MongoDB Atlas

## Installation

### Frontend

```bash
cd frontend
npm install
npm start
